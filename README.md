# Cosmium

Stealth Chromium browser toolkit for scraping and automation with fingerprint spoofing.

## Crates

| Crate | Description |
|-------|-------------|
| [`cosmium-cli`](./apps/cli) | Command-line interface |
| [`cosmium-engine`](./apps/engine) | Core engine — domain, application, infrastructure, presentation |
| [`cosmium-config`](./.config) | Configuration, environment, and logging |

## Install

```sh
cargo install cosmium-cli
```
