## The prebuilt browser

The [downloadable browser](/start/download/) is a modified build of Chromium.
The MIT License covers only Cosmium's own changes. It does not relicense
Chromium or anything Chromium bundles.

Every browser archive contains:

| File | Contents |
| --- | --- |
| `LICENSE.chromium` | the BSD-style license of the Chromium project |
| `THIRD_PARTY_LICENSES.txt` | the notices of every third-party component linked into that binary, generated by Chromium's own license tooling |
| `LICENSE.cosmium` | the MIT License for Cosmium's changes |
| `NOTICE` | a summary of the above, plus the codec, trademark, and warranty notes below |

### Media codecs

The prebuilt browser enables proprietary media codecs, including H.264 and AAC
through FFmpeg, so that it behaves like a regular desktop browser. These
formats may be covered by patents in some jurisdictions, and you are
responsible for any licenses your use requires. To avoid them, build the
browser yourself with `proprietary_codecs = false` in `.config/args.gn`.
